# Code of Conduct

Airy adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([español](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)).

## In short

- Be respectful and welcoming, in any language.
- Critique code and ideas, not people.
- No harassment, insults, discriminatory language, or publishing someone else's private information.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through the GitHub profile
[@luis-guillen](https://github.com/luis-guillen). Reports are handled confidentially. The maintainer may
remove contributions or block participants who break this code.
